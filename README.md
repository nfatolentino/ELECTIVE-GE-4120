        System for E-Wallet Users</b>
    </p>

    <p>
        This project focuses on the growing risk of e-wallet
        scams and the need for stronger cyber-hygiene practices.
    </p>

    <p>
        The proposed system would help users check suspicious
        messages and links, protect their financial information,
        receive cyber-hygiene reminders, learn about common scams,
        and report suspicious activities.
